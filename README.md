# Sleep Planner

Идея: помочь студенту рассчитывать время отбоя и подъёма и оценивать недосып.
Автор: Александр Крючатов (Alex Kryuchatov). Идея появилась 20 сентября 2026 года.

Сервис будет только считать и не хранить пользовательские данные.
Все результаты - оценки по средним значениям, не медицинская рекомендация.
